# Legacy v1 evaluation scripts

These scripts came with the repository as received (Stradiva v1). They
exercise the v1 modules (`backend/agent`, `backend/api/process_video.py`,
`backend/multiview`, `backend/behavior`). They are kept to reproduce the
baseline findings in `docs/archive/README.md`. Document references inside
them point to files that now live in `docs/archive/`.

The current evaluation is in `evaluation/experiments/` and
`evaluation/real/`. See `docs/EVALUATION.md`.

# Licence choice for Stradiva's own code

**Chosen licence: Apache License 2.0** (`LICENSE`, `NOTICE`), the same licence
as OpenCV. Below is the evaluation behind the choice.

## What constrains the choice

| Constraint | Effect |
|---|---|
| Runtime dependencies: OpenCV (Apache-2.0), NumPy and SciPy (BSD-3-Clause), FastAPI (MIT) | All permissive. Any permissive licence or a copyleft one is compatible. Nothing forces copyleft. |
| UI dependencies: Next.js, React, Recharts, Tailwind (MIT); fonts under OFL-1.1 | Permissive. The fonts must stay under OFL. That is satisfied by shipping the @fontsource packages unmodified. |
| Bundled data: one comma2k19 segment (MIT) | The MIT notice must travel with it: `licenses/comma2k19-MIT.txt`, referenced from `NOTICE`. |
| Model downloaded at build/run time: YOLOX-S from the OpenCV Model Zoo (Apache-2.0) | Same licence as the project, so no conflict. Not redistributed in the repository; its licence text is in `licenses/opencv_zoo_yolox-Apache-2.0.txt` and it is listed in `NOTICE` because the container image does include it. |
| Not bundled: comma speedchallenge video (no licence) | Not redistributed under any choice. It is fetched by script for evaluation only. |
| Competition | Judges must be able to run and inspect the code. Any OSI licence allows that. No specific licence was found in the official rules. |
| Intended users: forensic engineers, insurers, public agencies | These users often embed tools in proprietary workflows. Copyleft would deter adoption, and a patent grant reduces their legal risk. |

## Options compared

| | MIT | Apache-2.0 | GPL-3.0 / AGPL-3.0 |
|---|---|---|---|
| Permissive, embeddable | Yes | Yes | No: derivatives must be GPL. AGPL also covers network use. |
| Explicit patent grant and patent-retaliation clause | No | **Yes** | Yes (GPL-3) |
| Requires stating changes, and a NOTICE file | No | Yes (light burden) | n/a |
| Matches OpenCV's own licence | No | **Yes** | No |
| Prevents a closed fork of a forensic tool | No | No | Yes |

The case for Apache-2.0 over MIT is the explicit patent licence. Projective
calibration and accident reconstruction are areas with commercial patents,
and the downstream users are risk-averse. Matching OpenCV's licence also
keeps the notice story simple. The case for copyleft is that a forensic tool
benefits from staying inspectable. That is a real argument, and it is the
main reason to reconsider. We judged that adoption and inspectability are
both better served by a permissive licence plus a public repository.

## What the licence does not cover

* Synthetic footage generated by the simulator is the project's own output
  and falls under the code's licence.
* Results JSON files are factual measurements. They are released with the
  repository under the same terms.
* Use of Stradiva's outputs in legal proceedings is not authorised or
  validated by any licence. See the responsible-use section of the
  technical report.
